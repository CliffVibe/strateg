# T02. Тренировочный проект
Выбрать задачу, похожую на будущий бриф, **только на открытых данных**. Варианты:
- «Стоит ли оператору запускать сервис семейной геолокации для детей как отдельное платное приложение?»
- «Почему мобильные приложения операторов теряют ежедневную аудиторию и что с этим делать?»
- «Кому и как продавать eSIM для путешествий российским пользователям в 2027?»

Пройти весь путь: `/start` → … → `/report`. Человек отвечает на ворота как настоящий руководитель продукта.
- [ ] Отчёт `report.html` открывается, ссылки ведут на источники
- [ ] `strat check` — ноль ошибок
- [ ] Записано: время, стоимость, сколько раз помогал человек, где агент ошибся (→ `docs/process/ai-errors.md`)
- [ ] Скриншоты ключевых моментов → `docs/process/screenshots/`
