# 05. Сравнение с исходным способом

Цель — честно измерить, насколько агент лучше/дешевле/быстрее, **и какой ценой**.

## Участники
- **A. Обычный чат** — та же модель, один подробный промпт с задачей и теми же материалами, без инструментов агента (веб-поиск разрешён).
- **B. Агент** — этот репозиторий, полный путь.
- **C. Вручную** (опционально) — оценка времени аналитика по шагам на одной задаче (или собственный замер на части работы).

## Задачи
2–3 задачи руководителя продукта на открытых данных (одна — демо-проект). Одинаковые входы для A и B.

## Метрики
| Метрика | Как считаем |
|---|---|
| Время до результата | от запроса до отчёта; отдельно — время человека (ответы на ворота, правки) |
| Стоимость | A: usage чата; B: `strat cost`; C: часы × ставка (допущение) |
| Проверяемость | доля существенных утверждений со ссылкой на источник, который открывается и подтверждает утверждение |
| Ошибки | утверждения, не подтверждающиеся источником (ручная проверка выборки 20 шт.) |
| Честность | названы ли пробелы; выдана ли синтетика/догадка за факт |
| Варианты | число содержательно разных; есть ли «оставить как есть» / «закрыть»; качество возражений (1–5) |
| Согласованность | обещания ↔ продукт; одна аудитория в двух стратегиях (да/нет по чек-листу) |
| Полезность для решения | слепая оценка 1–5 человеком (не знает, где A, где B) |

## Протокол
1. Зафиксировать промпт A и версии моделей в `eval/<задача>/`.
2. Прогнать A и B; сохранить результаты как есть.
3. Обезличить (убрать признаки «агента») и отдать на слепую оценку.
4. Таблица результатов в `eval/results.md` + честные выводы: где агент проиграл (обычно — время и цена).
