# 02. Архитектура

## Схема
```
Пользователь ⇄ основной агент (Claude Code / Cursor, правила AGENTS.md)
                 │  навыки /start /resume /research /options /strategy /report /revise /decide /status /cost
                 │
                 ├─ субагенты: researcher(sonnet) · verifier(haiku) · red-team(opus) · respondent(haiku) · analyst(sonnet)
                 │
                 ├─ scripts/strat.py  ← единственный путь записи в реестры и состояние
                 │      new/use/status/stage · q · source · claim · impact · decision · check · cost · render · hook
                 │
                 ├─ хуки: SessionStart(состояние) · PreToolUse(защита) · PostToolUse(инструкции в источниках) · Stop(стоимость)
                 │
                 └─ файлы: knowledge/ · memory/ · projects/<slug>/{inputs,snapshots,work,costs, *.jsonl, state.json, journal.md}
```

## Модель данных проекта
| Файл | Записи |
|---|---|
| `state.json` | этап, история этапов, ворота (pending/question), next_action, бюджет, last_turn_at |
| `plan.json` | вопросы Q: текст, why (как меняет решение), метод, статус todo/doing/done/failed, попытки, утверждения-ответы |
| `sources.jsonl` | S: тип (web/doc/data/interview/user/calc/synthetic), заголовок, url/path, издатель, дата, цитата, снимок, sha256, надёжность |
| `claims.jsonl` | C: тип (fact/hypothesis/forecast/assumption), текст, источники, depends_on, уверенность, раздел, статус active/superseded/retracted |
| `decisions.jsonl` | D: что решили, выбрано/отвергнуто, ответственный, метрика, дата и условие пересмотра, based_on (C), обязательства |
| `journal.md` | хронология действий: action/human/gate/research/source/claim/revision/decision/routing/security/error |
| `costs/<session>.json` | стоимость сессии из транскрипта (по моделям, токенам, веб-поискам) |

Правила целостности — **в коде**, а не только в промпте: источник не записывается, если его цитаты нет в снимке
(нормализация регистра, кавычек, тире, пробелов; «…» — пропуск) или домен не входит в разрешённые (`strat allow`);
`strat check` ловит снимок, изменённый после регистрации (sha256), и факт на веб-источнике без снимка; цитаты в PDF и
изображениях код прочитать не может — их проверяет `verifier`; факт без несинтетического источника не создаётся; прогноз без основания
не создаётся; через ворота нельзя пройти без `--approved`; нельзя перепрыгнуть этап; реестры нельзя править в обход CLI (хук).

## Анализ влияния
Граф: источник → утверждения (sources) → зависимые утверждения (depends_on, транзитивно) → документы (ссылки `[C…]` в work/ и
report.md) → решения (based_on). `strat impact S004` проходит граф; `strat check` ловит ссылки на отозванные утверждения;
`strat decision review` — решения с изменившимися основаниями, наступившими датами, просроченными обязательствами.

## Работа с контекстом (экономия)
- AGENTS.md — компактный; методология грузится по одному файлу на этап.
- Поиск и чтение страниц — в субагентах: основной контекст получает 5–10 строк вывода, а не страницы.
- Состояние — в файлах: новый чат дешевле длинного (хук даёт выжимку при старте).
- Дешёвые модели на проверках и синтетике, сильная — на возражениях; эскалация при низкой уверенности.

## Учёт стоимости
Хук `Stop` читает транскрипт сессии (`transcript_path`), суммирует usage **по уникальным `message.id`** — Claude Code пишет одно
сообщение в несколько строк (проверено на реальном транскрипте: 232 строки → 91 сообщение; наивный подсчёт завышал бы ×2,5).
Учитываются вход, выход, кэш 5 мин и 1 час, чтение кэша, веб-поиск; транскрипты субагентов, если есть. Файл сессии перезаписывается
целиком → повторный вызов не удваивает сумму. Цены — `config/pricing.json`.

**По проектам, а не по сессиям.** `strat new/use` пишут время активации в `projects/.activity.jsonl`; каждое сообщение
транскрипта относится к проекту, активному в его момент. Разговор до `/start` (или разработка агента) ни на какой проект
не списывается, а смена проекта посреди сессии делит стоимость правильно (найдено в T01: песочнице досталась вся сессия
разработки — $1,51 при бюджете $1).

**Бюджет — ограничитель, а не уведомление.** `PreToolUse` перед WebSearch/WebFetch/субагентом пересчитывает стоимость
на лету (Stop-хук обновляет её только в конце хода) и при превышении блокирует действие с инструкцией: остановиться,
доложить, спросить. Поднять лимит — `strat budget N --approved` после ответа человека (запись `human` в журнале).
Дешёвые действия (чтение, запись черновиков, `strat`) не блокируются — агент может доложить и сохранить состояние.

**«Как получен результат»** собирает `strat render` (или `strat how`) из журнала, реестров и `costs/` на место
`<!-- strat:how -->` в `report.md` — числа совпадают с данными, модель их не пересказывает.

## Устойчивость
- Атомарная запись JSON (tmp → replace) — сбой посреди записи не портит реестр.
- Вопросы исследования со статусами; `q start` на `done` запрещён без `--force` — нет незаметных повторов.
- Источники дедуплицируются по URL+хэшу / пути.
- Ошибки инструментов — в журнал (`--kind error`), вопрос → `failed` с причиной; видно в `status`.
- Сбой хука не роняет работу, но пишет ошибку в stderr.

## Безопасность
- Материалы — данные: `injection-scan` (EN/RU паттерны) после WebFetch/WebSearch/Read добавляет агенту предупреждение и пишет в журнал.
- `inputs/`, `snapshots/` неизменяемы; реестры — только через CLI; AGENTS.md и методология — только в режиме `STRAT_DEV=1`.
  Хук `protect` проверяет и Write/Edit, и команды Bash/PowerShell (перенаправление `>`, `cp`/`Copy-Item` по адресату,
  `rm`/`mv`/`Set-Content`/`sed -i`…). Новый материал — `strat input add` (без перезаписи, sha256 в журнале); новый снимок
  страницы — Write нового файла в `snapshots/`, изменить существующий нельзя. Это эвристика против случайного и
  «подсказанного» обхода, не песочница: надёжная граница — права ОС.
- Хуки читают stdin как UTF-8 явно: на Windows Python по умолчанию декодирует его в cp1251, и русские шаблоны
  `injection-scan` не срабатывали (найдено в T01; тест запускает хук подпроцессом с `PYTHONIOENCODING=cp1251`).
- Секреты: только `.env` (в .gitignore), чтение запрещено правами и хуком.
- ПДн: `strat check` ищет email/телефоны/номера документов в `inputs/`.

## Переносимость
Cursor читает `AGENTS.md`, `CLAUDE.md`, `.claude/agents/`, навыки Claude и импортирует хуки Claude Code (по обзору spotdev.co.uk, 21.10.2026;
проверить в T07). Всё состояние — в файлах проекта и не зависит от среды. CLI `strat` работает из любого терминала.
