# Память между проектами

Здесь — только **уроки и предпочтения**, которые полезны в следующих задачах. Не факты о мире.

| Файл | Что | Пример |
|---|---|---|
| `preferences.md` | как пользователь хочет получать результат | «Отчёт для CPO — не длиннее 2 страниц, рекомендация первой строкой» |
| `lessons.md` | что сработало / не сработало в процессе | «Отзывы в RuStore по теме X малоинформативны — 80% про тарифы» |

Правила:
- Каждая запись: дата, проект-источник, текст, статус (`active` / `retracted` с причиной).
- Память **не является источником** для `strat claim add`. Факт из прошлого проекта — перепроверь и заведи источник заново.
- Устаревшее не удаляй молча — помечай `retracted: <дата> <почему>`.
