# Юнит-экономика

## Минимальная модель
- Единица: пользователь / подписчик / заказ — выбери одну и держись её.
- **Выручка на единицу** (ARPU/ARPPU) × **срок жизни** (из удержания) = LTV (валовой — после переменных затрат).
- **Стоимость привлечения** (CAC) по каналам.
- LTV/CAC, срок окупаемости CAC (месяцев).
- Постоянные затраты на запуск и поддержку → сколько единиц нужно для окупаемости.

## Правила
- Модель — кодом в `work/calc/unit-economics.py`, допущения — отдельными переменными сверху, каждое = `assumption` в реестре.
- Анализ чувствительности: какие 2–3 допущения сильнее всего меняют вывод? Они — в план проверки.
- Для телеком-продуктов учитывай каннибализацию и влияние на отток базовых услуг (может быть главной ценностью).
- Не выдавай диапазон за точку: «LTV 900–1 400 ₽ при удержании 35–50% на M6».
