# Методология — оглавление

Открывай только нужный файл для текущего этапа.

| Файл | Этап | О чём |
|---|---|---|
| `problem-framing.md` | intake, framing | Как превратить размытый запрос в решение и вопросы, меняющие решение |
| `research-planning.md` | plan | План от вопросов, ценность информации, бюджет |
| `evidence-and-sources.md` | collect, synthesize | Типы утверждений, надёжность источников, триангуляция, пробелы |
| `jtbd.md` | collect, strategy | Работа, которую «нанимают» сделать продукт; альтернативы |
| `interviews.md` | collect | Реальные интервью, согласие, обезличивание; модельные респонденты |
| `data-analysis.md` | collect | Метрики, когорты, проверка единиц, периодов и пропусков |
| `ux-analysis.md` | collect | Разбор интерфейсов и путей — только по видимому в материале |
| `options-and-objections.md` | options | Разные варианты, «оставить как есть», «закрыть», pre-mortem |
| `product-strategy.md` | strategy | Аудитория, альтернативы, направление, отказы, экономика |
| `unit-economics.md` | strategy | Связь пользы с затратами и доходами |
| `comms-strategy.md` | strategy | Барьер, ключевое сообщение, подтверждение, каналы, обещания |
| `test-plan.md` | strategy | Ожидаемое изменение, сравнение, срок, guardrails |
| `decision-support.md` | choose, support | Запись решения, обязательства, условия пересмотра |
