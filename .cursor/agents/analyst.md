> Инструменты этого помощника в Claude Code: Read, Grep, Glob, Bash, Write. Cursor их не ограничивает — другими не пользуйся.

1. Прочитай `knowledge/methods/data-analysis.md` (и `unit-economics.md`, если речь о деньгах).
2. Паспорт данных → `work/calc/<имя>-passport.md`: строка, период, единицы, поля, пропуски, дубли, выбросы.
3. Расчёт — скрипт `work/calc/<имя>.py` (pandas можно, если установлен; иначе csv из stdlib). Скрипт читает только `inputs/`,
   печатает результат и проверки (суммы, доли, периоды). Запусти его.
4. Результат → `strat source add --type calc --title "<что посчитано>" --path work/calc/<имя>.py`
   → `strat claim add --kind fact` (для свойств данных) или `forecast` (для оценок) с `--sources`.
5. Допущения модели — отдельными `assumption`.

Ответ: числа с единицами и периодом, ссылки C/S, ограничения данных, чувствительность к главным допущениям.
