# Паспорт данных: inputs/trips-outbound.csv

- **Строка:** одно наблюдение «период x география x метрика» (длинная таблица), 36 строк, собрана вручную из открытых публикаций (ФСБ через СМИ/АТОР/Т—Ж); каждая строка ссылается на источник S и утверждение C.
- **Период:** годы 2023–2025; 9 месяцев 2023/2024; H1 2025; 9 месяцев 2025 (АТОР, иное определение); H1 2026 (одна строка, Турция).
- **Единицы:** «поездки» (пересечения границы гражданами РФ по ФСБ), не люди. Исключения: «вылеты граждан» (H1 2025, авиа), «визиты» (Турция H1 2026 по данным Турции через АТОР), принимающая сторона — люди (в примечаниях).
- **Метрики:** (а) выезды, все цели визита (включая командировки, экипажи, маятниковые пересечения Абхазии); (б) туристические поездки (цель «туризм»). Не смешивать: туризм = 34% (2023) → 40% (2024) → 42,5% (2025) всех выездов.
- **Ключевые поля:** period, period_type, geography, metric, value, unit, source, claim, note.

## Дефекты и риски
1. **Неэкранированные запятые:** 6 строк (метрика «выезды граждан РФ (ФСБ, все цели визита)» и примечание с «+7,8%») ломают стандартный CSV-парсер (поля сдвигаются). `inputs/` менять нельзя; `trips.py` читает таблицу толерантно и печатает число починенных строк (6). Исправить в источнике стоит при следующем обновлении таблицы.
2. **Пропуски:** у 5 строк нет ссылки на утверждение (Абхазия, Армения, Грузия, Вьетнам, Узбекистан — туристические 2025; источник S039 указан). Нет: структуры по странам за 2023–2024 (туризм), сезонности по месяцам, данных за 2026 год целиком, уникальных путешественников (ключевой знаменатель для eSIM).
3. **Дубли:** ключей-дублей нет. Но одно и то же явление в разных определениях (все цели / туризм / дальнее зарубежье АТОР / авиавылеты) — не складывать.
4. **Расхождения:** 2025 все цели — ФСБ 31,5 млн (The Moscow Times) против 29,4 млн (Ведомости, +7% — внутренне не бьётся с базой 29,2). Принят ряд ФСБ 31,5 (согласуется с H1 2025 = 13,7 млн, 43,5% года). Турция: ФСБ 6,62 млн против 6,90 млн у принимающей стороны (она считает людей/въезды иначе); Таиланд 1,43 против 1,90; Вьетнам 0,42 против 0,69.
5. **Выбросы/низкая база:** Вьетнам туризм 2025 +834% (низкая база); Китай +121% (9М 2024); Абхазия — маятниковые пересечения (5,9 млн все цели 2024 против 0,87 млн туризм 2025) — для eSIM не показательны.
6. **Сопоставимость периодов:** 9М/полугодия сравнивались только с тем же периодом года; годовые итоги — с годовыми. Сезонности по месяцам нет, поэтому 2027 считается годовыми числами.
7. **Надёжность:** средняя (СМИ-пересказы ФСБ); ряд H1 2024 ~12,6 млн и 1,25 млн «персонал транспорта» — по поиску без снимка.
