# Бриф — песочница T06 (проверка устойчивости агента)

**Это не продуктовая задача.** Проект создан для задачи разработки T06 (`docs/tasks/T06-resilience.md`):
обрыв сессии посреди collect, недоступный источник, идемпотентный учёт стоимости.

- **Вопрос:** три коротких справочных вопроса (Q01–Q03), ответы сами по себе решения не меняют.
- **Решение / получатель:** нет; проверяется поведение агента, а не выводы.
- **Разрешённые источники:** любые открытые (`*`).
- **Бюджет:** $2.
- **Ожидаемое поведение:** Q02 ведёт на несуществующий домен (`.invalid`) → `q fail` с причиной, работа идёт дальше;
  после обрыва `/resume` продолжает с прерванного вопроса и не повторяет `done`.
- **Удаление:** песочницу удаляет человек.
