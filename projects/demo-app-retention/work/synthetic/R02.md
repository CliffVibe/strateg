# R02 — модельный респондент (СИНТЕТИКА, не данные о спросе)

Роль: мужчина 27 лет, курьер, Москва; МегаФон 3 года; бюджетный Android; пополняет через банк по СБП; приложение открывает редко.
Модель: haiku (субагент respondent), 19.11.2026. Гайд — `guide.md`.

1. **Последний вход.** Пропал интернет у подъезда; приложение долго грузилось, код из SMS для входа не пришёл сразу — закрыл, включил «в самолёте», связь вернулась. Баланс так и не посмотрел.
2. **Неожиданное списание.** В банке — «МегаФон 199 ₽»; SMS оператора — короткое «списано». Читал форумы, думает, что подписка, но где искать — не знает; «на 199 рублей звонить рука не поднялась».
3. **Помощь.** Чат: бот предложил темы, ни одна не подошла, «другое» → ссылки в справку, которые без сигнала не грузились. Звонить некогда — на ногах весь день. Связь вернулась сама.
4. **Оплата.** Банковское приложение, СБП, 300–500 ₽: «в приложение оператора лезть неохота». Карту оператору не привязывал — «боюсь, что спишется само».
5. **Бросал.** «Мои услуги»: половину названий не понимает, боялся отключить нужное. Вход: восстановление пароля через SMS на тот же плохо работающий номер.
6. **Отзывы.** Не писал; читал в RuStore похожие жалобы. «Есть ли смысл, если оператор не отвечает».

**Гипотезы:** точка отказа — вход (SMS-код) раньше баланса и услуг; непонятное списание не выясняют, потому что непонятно, где искать; канал поддержки выбирают по моменту (в дороге, без сигнала); оплата через банк делает оператора невидимым — подписки не замечают.
**Гайд:** «списание / подписка / услуга / опция / тариф» абонент не различает; в. 4 и 6 — гипотетика.
