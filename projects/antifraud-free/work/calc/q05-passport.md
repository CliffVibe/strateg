# Паспорт допущений Q05 (точка безубыточности бесплатного расширенного уровня)

Данных в inputs/ нет; внутренних цифр МегаФона нет. Модель целиком на допущениях. Скрипт: `q05_breakeven.py`.
Единица: 1 млн абонентов; период: месяц (поток); деньги: ₽/мес; отток: доля/мес (в отчёте п.п.).
Пропусков, дублей, выбросов нет: данных нет. Диапазоны low/base/high заданы заказчиком задачи, не выведены из данных.

| Параметр | low / base / high | Что это | Основание |
|---|---|---|---|
| pen | 1 / 3 / 6 % | платный уровень сейчас, доля базы | нет данных; ориентир по рынку неизвестен |
| price | 149 / 199 / 249 ₽/мес | цена | рыночная вилка; цена МегаФона уточняется |
| m_svc | 50 / 65 / 80 % | маржа услуги после затрат ИИ/партнёров | допущение |
| adopt | 10 / 25 / 40 % | включат при бесплатной модели | допущение; ВЦИОМ: 1% называют защиту пожеланием [C013] |
| c_user | 5 / 15 / 30 ₽/мес | обслуживание 1 пользователя (ИИ, партнёр) | допущение |
| arpu | 400 / 500 / 600 ₽/мес | ARPU | допущение |
| m_arpu | 30 / 38 / 45 % | доля вклада в ARPU | допущение |
| churn | 1,5 / 2,0 / 2,5 %/мес | базовый отток | допущение; на абсолютный порог не влияет, только на % от оттока |
| life | 12 / 18 / 24 мес | срок вклада удержанного | допущение |
| seg (C) | 20 / 25 / 30 % | доля базы в бесплатном сегменте | из постановки |
| k_pay (C) | 0,7 / 1,0 / 1,5 | концентрация платящих в сегменте | моё допущение |
| arpu_x (C) | 1,0 / 1,3 / 1,6 | ARPU сегмента к среднему (старшие тарифы) | моё допущение |

## Логика
- A: вклад платного = N·pen·price·m_svc (опорный; эффект A = 0).
- B (бесплатно всем) vs A: -вклад платного - N·adopt·c_user (затраты на всех включивших); плюс удержание.
- C: то же в сегменте seg; платящие в сегменте = pen·k_pay.
- D: -вклад платного (экономия постоянных затрат и рост оттока платящих не учтены).
- Удержание: ценность = Δотток·N·ARPU·m_arpu·life, месячный поток сравнивается с месячным вкладом. Порог Δ: эффект = A.
- Δ в B - среднее снижение оттока по всей базе; в C - внутри сегмента (и в пересчёте на всю базу).

## Ограничения
- Нет дисконтирования, нет каннибализации ARPU (платящие, которые ушли бы при отказе), нет постоянных затрат запуска/маркетинга, нет эффекта на привлечение новых абонентов, нет роста оттока платящих при варианте D.
- Срок life=12-24 мес консервативнее равновесного (1/churn = 50 мес): порог завышен для долгой перспективы.
- Одинаковое adopt и одинаковое снижение оттока для всех включивших - упрощение.
- Диапазон «все вместе» - крайние сочетания, не вероятностный интервал.
