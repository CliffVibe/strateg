---
name: report
description: Собрать итоговый отчёт для принятия решения и HTML-версию со ссылками на источники (этап package).
---
1. `verifier` по всем фактам, на которых держится рекомендация → исправь.
2. `report.md` по шаблону: рекомендация сверху, затем ситуация, варианты, стратегии, план проверки, решения. Читается за 10 минут.
   «Как получен результат»: числа (этапы, время, источники, доли фактов/гипотез/прогнозов, участие человека, стоимость
   по моделям) **не пиши** — их вставит `strat render` на место `<!-- strat:how -->`. Под блоком своими словами:
   где помогал человек, где агент ошибся и что исправил, главные ограничения вывода.
3. `strat check` — ноль ошибок. `strat render` → `report.html`.
4. Скажи пользователю, где файл, и одно-два ключевых ограничения вывода.
5. `strat stage support --note "отчёт сдан" --next "decision review через N недель"`.
