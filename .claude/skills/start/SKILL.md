---
name: start
description: Начать новую задачу руководителя продукта — интейк и постановка (этап intake). Использовать, когда пользователь приносит новый вопрос или материалы.
---
1. Придумай короткий slug и название, спроси бюджет работы агента (по умолчанию $5). `python scripts/strat.py new <slug> --title "…" --budget N`.
2. Если пользователь приложил файлы — попроси положить их в `projects/<slug>/inputs/` или добавь сам:
   `python scripts/strat.py input add <путь> [--name <имя>]` (копия без перезаписи, sha256 в журнале).
   Другие способы записи в `inputs/` хук блокирует — это правильно.
   Бегло просмотри материалы: что это, период, объём. Не анализируй глубоко — это позже.
2a. Спроси (или возьми из запроса) разрешённые источники и запиши: `python scripts/strat.py allow add <домен> …`
   (`'*'` — если человек разрешил любые открытые). Источник с другого домена `strat source add` не примет.
2b. Прочитай `memory/lessons.md` и `memory/preferences.md` (только `active`): учти уроки прошлых проектов в плане и вопросах,
   скажи пользователю одной строкой, какие учёл. Это уроки процесса, а не факты: факт из прошлого проекта перепроверь
   и заведи источник заново.
3. Прочитай `knowledge/methods/problem-framing.md`. Заполни `brief.md` тем, что уже известно (с пометкой «откуда известно»).
4. Задай пользователю **только недостающие** вопросы из интейка — не больше 3–5, с вариантами ответа (AskUserQuestion, если есть).
   Незаданное — запиши как допущение и покажи.
5. Покажи итоговую постановку (5–8 строк) и спроси: «Верно? Можно идти дальше?»
6. После «да»: `strat stage framing --approved --note "<суть подтверждения>" --next "Сформулировать вопросы, меняющие решение"`.
