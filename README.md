# Стратег продукта — ИИ-агент для руководителя цифрового продукта

Репозиторий-агент для конкурса «Стратег Фабрики продуктов» (МегаФон). Открываешь папку в **Claude Code** или **Cursor** —
и агент ведёт от размытого вопроса («почему падает удержание?») к проверяемой картине ситуации, ≥ 3 вариантам с возражениями,
согласованным продуктовой и коммуникационной стратегиям, плану проверки — и помогает после решения.

> Только открытые источники и собственные материалы. Не содержит и не использует закрытых данных МегаФона или других компаний.

## Запуск за 3 шага

**Нужно:** Claude Code (или Cursor), Python 3.10+ (`python` или `python3` в PATH), Git. Подписка Claude или ключ API.
Платные сервисы сверх этого — **не нужны**. Необязательно: ключ Jev (TypeSafe) для дешёвой классификации — см. `docs/04-tooling.md`.

1. `git clone https://github.com/CliffVibe/strateg.git && cd strateg` → `python -m unittest discover -s tests`
   (на macOS/Linux — `python3`; должно быть OK).
2. `claude` в папке → доверить папку. Хук покажет: «Активного проекта нет».
3. Напиши: **«/start — хочу понять, почему падает удержание в нашем приложении»** (или свою задачу) и приложи материалы.

Дальше агент сам предложит шаги и остановится там, где нужен ваш выбор.

| Хочу… | Сказать агенту |
|---|---|
| начать новую задачу | `/start` + описание |
| продолжить после перерыва (в т. ч. в новом чате) | `/resume` (или просто «продолжим») |
| понять, где мы и сколько стоило | `/status`, `/cost` |
| остановить / уточнить / исправить | «стоп», «уточняю задачу: …», «исправь: …» |
| добавить новые данные | `/revise` + файл или факт |
| разрешить потратить больше (агент остановился на бюджете) | «поднимай бюджет до $N» |
| после решения: что пересмотреть | `/decide` |

## Что получится

`projects/<задача>/report.html` — отчёт для решения за 10 минут: рекомендация, ситуация (факты, гипотезы, прогнозы — цветом),
варианты с возражениями, стратегии, план проверки, решения и условия пересмотра, «как получен результат» и стоимость.
Каждое утверждение кликабельно ведёт к источнику.

```

knowledge/methods/   методология: постановка, исследование, доказательства, JTBD, интервью, данные, UX, варианты, стратегии, проверка
templates/           структура артефактов
memory/              уроки и предпочтения между проектами (не факты)
projects/<slug>/     одна задача: inputs/ (сырьё) · snapshots/ · реестры *.jsonl · state.json · journal.md · work/ · report.md · costs/
scripts/strat.py     CLI: состояние, реестры источников/утверждений/решений, анализ влияния, проверки, стоимость, рендер, хуки
.claude/             5 субагентов · 10 навыков · хуки (состояние при старте, защита сырья, поиск внедрённых инструкций, учёт стоимости)
.cursor/             для Cursor: те же хуки в формате Cursor (hooks.json) и субагенты (генерирует strat cursor-sync)
docs/                концепция, архитектура, план, инструменты, протокол сравнения, задачи разработки, журнал
```

## Ограничения

- Агент не заменяет реальные интервью и данные: модельные респонденты дают только гипотезы.
- Открытые источники по российскому рынку часто без методологии — агент помечает их низкой надёжностью и говорит о пробелах.
- Стоимость на подписке — оценка в ценах API (цены — `config/pricing.json`, сверять перед сдачей).
- Хуки запускаются через bash (на Windows — Git Bash, ставится вместе с Claude Code) и берут `python`, а если его нет —
  `python3`. Если на Windows есть только `py` — замените в `.claude/settings.json`.

### Cursor (нужен ≥ 3.0.0)

Правила (`AGENTS.md`) и навыки (`.claude/skills/`, вызов через `/`) Cursor берёт сам — при включённой настройке
Settings → Agents → Third-Party Imports («Include Third-Party Plugins, Skills, and Other Configs», включена по умолчанию).
Что отличается от Claude Code:

- **Хуки** работают из `.cursor/hooks.json`, а не из `.claude/settings.json`. У Cursor свои имена инструментов (`Shell`
  вместо `Bash`, `Write` вместо `Edit`) и свой формат входа, а на Windows хуки идут через PowerShell. Хуки из `.claude/`
  Cursor тоже запускает, но они ничего не делают, чтобы не срабатывать дважды.
- **Субагенты** — копии в `.cursor/agents/` с `model: inherit` (как у основного чата): алиасы `sonnet`/`haiku`/`opus`
  Cursor не описывает. Значит, маршрутизация по моделям (AGENTS.md §5) в Cursor не работает, пока не задать id моделей:
  `python scripts/strat.py cursor-sync --models haiku=<id>,sonnet=<id>,opus=<id>`. Ограничения инструментов субагентов
  (`tools:`) в Cursor нет — они записаны в текст субагента. После правки `.claude/agents/` — `strat cursor-sync`
  (тест следит за расхождением).
- Проверено в Cursor CLI 2026.11.11 (см. `docs/tasks/T07-portability.md`); окно редактора — по чек-листу там же.
- **Стоимость** хук считает только по транскриптам Claude Code (а `stop` в `agent -p` Cursor не вызывает). Работу в Cursor записывайте вручную в
  `projects/<slug>/costs/cursor.manual.jsonl` (`{"what": "Cursor, сессия …", "usd": …}`) по данным Cursor Usage.
  Бюджет-стоп считает только то, что записано.
- **Секреты**: запреты чтения из `.claude/settings.json` Cursor не переносит — `.env` закрыт через `.cursorignore`.
- Если импорт из `.claude/` выключен: `python scripts/strat.py cursor-sync --skills` копирует навыки в `.cursor/skills/`.
